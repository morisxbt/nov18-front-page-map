# Wednesday 18 November 2026

An original broadsheet news graphic pairing illustrated lead stories and brief reports with a world map, regional counts, and a date-check panel.

Run `python3 main.py` to copy the pre-rendered `entry.png` to `/output/entry.png`. Set `MAKEFUN_OUTPUT_DIR` to choose another destination, for example `MAKEFUN_OUTPUT_DIR=out python3 main.py`.

Regenerate the image with `python3 draw_news.py` (requires Pillow). The script writes `entry.png` beside itself.
